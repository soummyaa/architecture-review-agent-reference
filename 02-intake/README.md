# Module 02: Intake

## Goal

Read a synthetic technology-review submission from SharePoint through
Microsoft Graph and convert it into a typed intake contract.

## Prerequisites

- Completed [Module 00](../00-setup/README.md), including validated SharePoint
  access.
- A synthetic submission stored in the workshop SharePoint site when this
  module is implemented.

## Run Standalone

This module is scaffolded but not implemented yet. No executable command is
available. Its future implementation must read a synthetic submission and run
without importing code from another numbered module.
