# Architecture Review Agent Reference

Reference build for a hands-on multi-agent workshop on Microsoft Foundry. Each
numbered folder is a standalone module.

## Modules

| Module | Purpose | Status |
| --- | --- | --- |
| [00-setup](00-setup/) | Provision and validate workshop prerequisites | Implemented |
| [01-standards-agent](01-standards-agent/) | Compare proposals with architecture standards | Scaffold only |
| [02-intake](02-intake/) | Read technology submissions from SharePoint | Scaffold only |
| [03-orchestration](03-orchestration/) | Coordinate the specialist agents | Scaffold only |
| [04-research](04-research/) | Research technologies from approved sources | Scaffold only |
| [05-adr-generation](05-adr-generation/) | Generate and publish an ADR as a Word document | Scaffold only |
| [06-review-eval](06-review-eval/) | Review and evaluate agent output | Scaffold only |

Start with [00-setup](00-setup/README.md). Modules marked scaffold only contain
their workshop contract but no executable implementation yet.
